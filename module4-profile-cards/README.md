# Module 4 — React Profile Card Application

MCON 505: Front-End Frameworks. A student directory built with React, TypeScript and Vite.

## What it demonstrates

- JSX and functional components (`Header`, `StudentCard`, `Footer`)
- Typed props via the `StudentCardProps` interface
- Component composition in `App.tsx`: header, course summary section, five student cards, footer
- Basic CSS styling in `App.css`

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

## Build

```bash
npm run build
```
