# Module 2 — Typed Data Transformer

A TypeScript application built with Vite that retrieves user data from the JSONPlaceholder API and displays the results.

## Features

- TypeScript interface for user data
- Status type alias and union types
- Optional phone property
- Typed user-formatting function
- Generic function demonstrated with numbers, strings, and user objects
- API data fetching and display

## Requirements

- Node.js
- npm

## Installation

```bash
npm install
```

## Running the Application

```bash
npm run dev
```

Open the local URL displayed by Vite.

## Production Build

```bash
npm run build
```

## API

https://jsonplaceholder.typicode.com/users
